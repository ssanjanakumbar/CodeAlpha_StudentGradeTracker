# Student Grade Tracker

A simple Java console-based application developed as part of the CodeAlpha Java Programming Internship.

## Features

- Enter the number of students
- Enter student names
- Enter grades for each student
- Validate grades between 0 and 100
- Calculate the average grade
- Find the highest grade
- Find the lowest grade
- Display a summary report of all students

## Technologies Used

- Java
- ArrayList
- Scanner
- IntelliJ IDEA

## How to Run

1. Open the project in IntelliJ IDEA.
2. Open `src/Main.java`.
3. Run the `Main` class.
4. Enter the number of students.
5. Enter each student's name and grade.
6. The program will display the summary report.
